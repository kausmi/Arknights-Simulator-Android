## 这是什么

把原作的三个模块完整搬到手机上：

| 模块 | 说明 |
| --- | --- |
| **自由沙盒** | 自由部署干员、生成敌人、编辑地形，测技能与伤害 |
| **游玩自制关卡** | 导入 JSON 关卡，自由编队，体验完整战斗与结算 |
| **关卡制作器** | 编辑地图、敌人路线与出生时间，支持试玩与分享 |
| **干员数值调整** | 安卓版新增：改基础数值、模组、天赋、职业特性（见下） |

界面是原作的终端风，配色、文案、排版都是原来那套；本版只按手机屏幕重新排了尺寸。

## 安卓版专属特性

这些是原仓库没有、为手机单独做的：

### 1. 单文件 APK，内置全部运行时

- **不需要装 Node.js**。原作的服务端（发静态文件 / 关卡库读写 / 音乐列表）用 Java 重写，
  首次启动把网页资源解到应用私有目录，直接开跑。
- **内置 Python 运行时**，用于从手机上的《明日方舟》提取官方美术。
- 全程本地运行，**不联网、不需要账号**。

### 2. 直读手机上的《明日方舟》资源

原作的素材要从桌面版客户端提取；本版改成**直接读手机本地的方舟**：

- 路径：`/storage/emulated/0/Android/data/com.hypergryph.arknights/files/Bundles`
- 这个目录属于方舟自己，普通应用（包括拿到「所有文件访问权限」的应用）都读不到，只有 shell 身份能进。
  所以本版用 **Shizuku**（开源、无需 root）借一个 shell 身份，**直接把 bundle 喂给解析器**，
  中间不落到任何压缩包或副本，产出直接写进本应用自己的目录。
- 需要你在设置里点「读取方舟资源」，并按提示授权 Shizuku。**没走通也能玩**，
  只是官方美术会换成替代素材，玩法与数值完全不受影响。

#### 提取出来的图片存在哪

**只存在 App 自己的私有目录**（`/data/user/0/com.arksim.app/files/web`）：

- **不进相册、不进媒体库**，文件管理器也翻不到；
- 提取时 python 只在自己的一次性临时目录里过一手，转存完立即删除，
  所以整个过程不会在你手机里留下任何能被媒体扫描发现的图片；
- 卸载 App 时这些文件一起清掉。

> 0.1.1 及更早版本把图放在了 `Android/data/com.arksim.app/files/web`（外部专属目录），
> 那个位置会被相册当成照片扫进去。0.1.2 启动时会自动删掉旧目录并通知媒体库刷新。

### 2.1 支持切换读取的客户端（官服 / B 服）

不同服、不同渠道的《明日方舟》是不同的应用包名，资源目录也随之不同。设置里可以指定读哪一个：

| 客户端 | 包名 | 状态 |
| --- | --- | --- |
| 简中 · 官服（默认） | `com.hypergryph.arknights` | 可用 |
| 简中 · B 服 | `com.hypergryph.arknights.bilibili` | 可用 |
| 国际服 · 英文 | `com.YoStarEN.Arknights` | 暂不可用 |
| 日服 | `com.YoStarJP.Arknights` | 暂不可用 |
| 韩服 | `com.YoStarKR.Arknights` | 暂不可用 |
| 繁中服 | `tw.com.hypergryph.arknights` | 暂不可用 |

- 默认是**简中官服**。
- 装了 B 服可以切过去，之后提取就读 B 服的 `Bundles` 目录。
- 其它语言服的包名已经登记好，但目前**暂时用不了**（资源目录结构与命名还没适配），
  界面上会显示「暂不可用」并且不可点，不会让你白试。

### 3. 干员详情页：数值、技能、模组、潜能、皮肤（原仓库没有）

一个独立的「干员数值」页面，进去其实是**干员详情页**：左边列表（可按职业 / 星级 / 有无模组 /
是否改过筛选，也能按名字搜），右边是这一位干员的全部信息与可改项，两块各占一半屏。

五类改动**各自独立存、独立还原**：

- **携带与潜能**：
  - **潜能 1～6 可切**，并且是按**每位干员自己的官方潜能表**折算的 —— 有人是「费用 -1」，
    有人是「再部署 -4 秒」，有人是「攻击 +25」，还有人是「天赋增强」，每个人的数值都不一样，
    不是统一加个百分比。切完下面的基础数值格子会把变化项标亮并显示增减量。
  - **携带技能可换**：换哪个技能，进沙盒打出来的就是哪个技能的效果（1/2/3 技能各有独立实现）。
  - **携带模组可换**：可以「不装模组」，也可以装这位干员的任意一个模组；装不装会**真的重算数值**
    （模组自带的生命/攻击/防御加成会叠回基础上，不装就退回无模组的基础值），模组替换的职业特性也会跟着换。
  - **立绘/皮肤可切**：精一 / 精二，加上从本机方舟解出来的时装（见下面第 5 节）。选了之后
    **沙盒里的立绘、手牌与牌库的头像会一起变**，不只是下拉框里记个名字。

- **基础数值**：生命上限、攻击、防御、法抗、部署费用、阻挡数、攻击间隔、攻速、
  再部署、技力回复、每秒回血、移动速度、嘲讽等级、重量等级。
- **模组**：模组等级、模组自带的属性加成、模组替换的职业特性、模组追加/加强的天赋。
  每个干员可能有 0～2 个模组，不同职业的模组不同。
- **天赋**：每个天赋的数值项（`bb` 里的键）单独可改。
- **职业特性**：特性里的数值项可改。

原则：**官方原表一个字节都不动**，改动单独存一份覆盖表。所以：

- 随时可以「只还原模组」「只还原天赋」，不影响你调过的基础数值；
- 「还原这位干员的全部」和「全部还原」都有一键入口。

支持**筛选**：按职业、星级、有无模组、是否已改过过滤，还有名字/id 搜索。

### 4. 干员列表跟得上游戏更新

干员列表不是写死的，而是**从本机方舟的 `skinpack/` 读**（每个干员一个 bundle，文件名就是 charId）。
游戏更新后出了新干员，列表会自动多出来，不需要等本仓库更新数据。

### 5. 皮肤（时装）可以真的切换

干员的时装立绘在方舟的 `skinpack/<charId>.ab` 里。为了不让首次提取变得很长，皮肤是**按需解**的：

1. 进「干员数值」页 → 选一位干员 → 「携带与潜能」里的「立绘/皮肤」；
2. 只有精一/精二两项的干员，下面会有一个「解这个干员的皮肤」按钮，点它；
3. 等 1～2 秒，下拉里就会多出这位干员的时装（如凯尔希的 `boc`、`sale`）；
4. 选中之后，**沙盒立绘、手牌和牌库的头像都会跟着换成这套时装**。

已解出的皮肤会留在应用目录里，升级 APK 不会丢。

> 为什么不做「一次解全部」：全量 434 个 `skinpack` 大约 11 分钟、160MB。
> 如果哪天需要，设置里「重新提取」的链路上留了开关。

### 6. 新增自定义干员（实验功能）

可以自己捏一位干员：名字、职业、**子职业**、位置、星级、伤害类型、全部基础数值、
**攻击范围**、最多 3 个技能。保存后会出现在牌库里，跟官方干员一样能上手牌、进存档。

攻击范围有三种给法：

- **沿用子职业范围**（默认）：选了子职业就自动套用这个分支的标准范围（内置 61 个子职业）；
- **用模板**：近战 / 近战三格 / 远程 / 远程 3×3 / 治疗，五个常用形状；
- **自己画**：7×5 的格子里点格子，自己想打哪就打哪（自己站的那格固定包含）。

> **实验功能，请注意边界**：数值不做任何平衡校核（填多少就是多少）；技能只支持数值型的基础描述
> （技力消耗 / 持续时间 / 伤害倍率 / 目标数），官方那套召唤物、复杂条件、多段位移不在支持范围内；
> 没有立绘与 Spine 小人，战斗里显示替代图标。

### 7. 手机操作与适配

- **横屏 / 竖屏 / 平板各有各的布局**：手机横屏时菜单与卡片自动收紧，平板则放宽。
- **没有黑边**：内容铺满整块屏幕，界面自己避开挖孔（刘海）与手势条 ——
  壳把实测的 inset 通过 CSS 变量喂给页面，页面据此排布。
- **战斗界面屏幕方向可设**：设置里可选「横屏（默认）/ 自动 / 竖屏」。
- **双指手势**：沙盒与编辑器里，两指张合可缩放镜头、两指拖动可平移；单指仍然只做选择与放置。
- **触控友好**：所有可点区域放大到 44px 以上，去掉「悬停才显示」的交互，输入框字号不小于 16px
  （避免聚焦时被浏览器放大）。
- **存档位 6 → 10 个**，每个都能自定义名称（最多 40 字）。

### 8. 教程与帮助

- **首次进入有引导**：五步讲完「这是什么 / 从哪开始 / 哪里改数值 / 资源怎么读 / 手册在哪」，之后不再出现。
- **设置里有「教程与帮助」**，含完整手册：首次上手、沙盒、编辑器、干员数值、读取资源、
  皮肤与小人、手机操作、常见问题。也可以直接从顶栏进。

### 9. 干员数值改动提示可关

改过数值后，进沙盒 / 作战会在顶部挂一条提示，说明当前用的是改后数值。
这条提示**可以点 × 当次收掉**，也可以去设置里把「干员数值改动提示」永久关掉（改动本身仍然生效）。

## 首次使用（Android）

1. 安装 `Arknights-Simulator-Android-0.1.15.apk`（[最新 Release](https://github.com/kausmi/Arknights-Simulator-Android/releases/latest)）。
2. 打开应用，等它把资源解到本地（首次较慢，之后秒开）。
3. 主菜单会弹一次引导，按提示走一遍即可。
4. **（可选）** 想要官方美术：设置 →「方舟本地资源」→ 点「开始提取」→ 按提示授权 Shizuku。
   提取时会显示进度条与「大约还要几分钟」。
5. **（可选）** 想改数值：主菜单 →「干员数值调整」。

### 想要官方美术，需要什么

- 手机上已安装《明日方舟》，并且**在游戏里下载完完整资源包**。
- 安装 [Shizuku](https://shizuku.rikka.app/)（开源免费，**无需 root**），按它提示用无线调试启动服务。

> Shizuku 服务重启后需要重新授权本应用；手机重启后要重新启动 Shizuku。
